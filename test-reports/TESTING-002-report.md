## Возможные будущие баги / риски

1. **`resolveAllowedPath()` разрешает только типы медиа `gallery` и `video`** — файлы изображений в настоящее время не могут быть удалены через существующий DELETE API загрузки. Задокументировано как будущий риск, не один из оригинальных 16 багов.

2. **Ограничение скорости заявок основано только на IP** — истинное fingerprinting устройства не реализовано. Может потребоваться усиление для сценариев с несколькими устройствами.

3. **Валидация калькулятора очищается при вводе** — ошибка очищается, когда пользователь печатает, но если пользователь полностью очищает поле, площадь становится пустой и валидация поймает это при следующей навигации по шагам.

4. **Баннер cookie может не соответствовать всем местным регламентам** — реализация хранит согласие в `localStorage`, но не покрывает все требования GDPR/CCPA. Может потребоваться усиление позже.

5. **Существующие неотслеживаемые файлы `.playwright-mcp/page-*.yml`** присутствовали в рабочем дереве до этой работы и не были затронуты во время этой сессии.
